## 八、测试执行计划

### 8.1 冒烟测试（每次部署后必做）
1. 管理员登录 → 查看学生列表 → 添加学生 → 调整分数
2. 教师登录 → 开始上课 → 查看签到统计
3. 学生登录 → 执行签到 → 查看分数历史
4. 验证数据一致性

### 8.2 完整回归测试（每周一次）
- 执行所有上述测试用例
- 重点测试最近修改的功能
- 验证核心业务流程

### 8.3 自动化测试建议
```bash
# 运行单元测试
pytest tests/unit -v

# 运行集成测试
pytest tests/integration -v

# 生成覆盖率报告
pytest tests/ --cov=backend --cov-report=html
```
