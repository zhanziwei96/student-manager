# ClassHub 班级管理系统 - 需求规格说明书

**文档版本**: v1.0  
**编写日期**: 2026-03-24  
**适用系统**: ClassHub 班级管理系统 v3.0+

---

## 1. 文档概述

### 1.1 目的
本文档定义 ClassHub 班级管理系统未来版本的功能需求，旨在从"签到工具"升级为完整的"教学管理系统"。

### 1.2 范围
涵盖教学管理核心业务：课程安排、考勤管理、作业任务、成绩评估、通知公告等。

### 1.3 术语定义

| 术语 | 定义 |
|------|------|
| 课程表 | 按周循环的排课计划 |
| 课堂会话 | 单次上课的签到时间段 |
| 平时成绩 | 由签到、作业、课堂表现组成的综合性评分 |
| 总评成绩 | 按权重计算的学期最终成绩 |

## 2. 功能需求

### 2.1 高优先级需求（核心功能）

#### REQ-001: 多班级并行上课
**优先级**: 🔴 高  
**需求描述**: 支持同一时间段多个班级同时上课，互不干扰  
**业务场景**: 上午1-2节，2025级中药学1班、2班、3班同时在机房上课，各班级独立签到  
**功能要求**:
- 教师可同时开启多个班级的课堂会话
- 每个班级有独立的签到状态
- 学生按所属班级进行签到
- 教师可在不同班级间切换管理

**验收标准**:
- [ ] 教师dashboard显示所有进行中的班级
- [ ] 学生签到时自动匹配所属班级的进行中的课堂
- [ ] 签到记录关联到具体班级和课堂会话
- [ ] 统计报表按班级分别展示

---

#### REQ-002: 课程表/排课系统
**优先级**: 🔴 高  
**需求描述**: 建立课程表，支持按周课表自动/手动开启签到  
**业务场景**: 每周三3-4节是中药学4班的计算机应用基础课，系统自动允许该时段签到  
**功能要求**:
- 管理员/教师可创建周课表
- 课程信息：课程名、班级、教室、时间段、任课教师
- 支持单周/双周/每周/自定义周期
- 课程开始时间自动开启签到（可配置）
- 节假日/调课管理

**数据模型**:
```
Course: 课程基本信息
Schedule: 周课表（哪节课在哪个时间）
CourseSession: 单次上课实例（关联签到）
```

**验收标准**:
- [ ] 可视化课表界面（教师视图）
- [ ] 到上课时间自动推送"开始上课"提醒
- [ ] 调课申请与审批流程
- [ ] 课表导入导出（Excel）

---

#### REQ-003: 作业/任务管理
**优先级**: 🔴 高  
**需求描述**: 教师发布作业，学生提交，批改后自动关联成绩  
**业务场景**: 教师发布"Excel表格格式设置练习题"，学生提交文件，教师批改后+10分  
**功能要求**:
- 教师发布作业：标题、描述、截止时间、附件、分数
- 学生提交：文字、图片、文件（支持多格式）
- 教师批改：评分、评语、退回重做
- 成绩自动计入"平时成绩"维度
- 作业状态追踪：未提交/已提交/已批改

**验收标准**:
- [ ] 作业列表按课程/班级筛选
- [ ] 文件上传支持拖拽
- [ ] 截止前自动提醒未提交学生
- [ ] 批改界面支持批注（图片/PDF）

---

### 2.2 中优先级需求（体验提升）

#### REQ-004: 通知/公告系统
**优先级**: 🟡 中  
**需求描述**: 教师可向班级/个人发送通知，追踪已读状态  
**功能要求**:
- 发送对象：全班/多班/个人
- 消息类型：公告、提醒、私信
- 已读回执
- 通知渠道：站内消息 + 可选邮件/微信推送
- 消息历史查询

**验收标准**:
- [ ] 消息角标实时更新
- [ ] 未读消息列表
- [ ] 重要公告置顶

---

#### REQ-005: 请假/缺勤管理
**优先级**: 🟡 中  
**需求描述**: 学生提交请假申请，教师审批，关联考勤  
**功能要求**:
- 学生提交请假：类型（事假/病假/其他）、时间、原因、附件
- 教师审批：通过/驳回
- 请假期间自动跳过签到
- 缺勤统计排除已批准请假
- 销假功能

**验收标准**:
- [ ] 请假申请流程完整
- [ ] 教师审批后学生收到通知
- [ ] 考勤报表区分"请假"和"缺勤"

---

#### REQ-006: 成绩多维度管理
**优先级**: 🟡 中  
**需求描述**: 支持多种成绩类型，配置权重，自动计算总评  
**功能要求**:
- 成绩维度：平时成绩、期中、期末、作业、课堂表现、签到率
- 权重配置：各维度占比（如平时30%+期末70%）
- 平时成绩子项：签到、作业、课堂问答等
- 自动计算总评
- 成绩曲线图（个人/班级）

**数据模型**:
```
ScoreCategory: 成绩维度定义
ScoreWeight: 权重配置
StudentScore: 学生各项成绩
```

**验收标准**:
- [ ] 成绩录入界面支持多维度
- [ ] 权重配置可视化
- [ ] 学生端查看成绩构成饼图
- [ ] 导出成绩单（PDF）

---

#### REQ-007: 数据导出/报表
**优先级**: 🟡 中  
**需求描述**: 导出各类统计报表，满足行政需求  
**功能要求**:
- 班级签到报表（按日/周/月）
- 个人学期成绩单
- 班级成绩对比分析
- 教师工作量统计
- 导出格式：Excel、PDF

**验收标准**:
- [ ] 报表模板美观
- [ ] 支持自定义时间范围
- [ ] 报表自动发送至邮箱（可选）

---

### 2.3 低优先级需求（锦上添花）

#### REQ-008: 积分商城/激励机制
**优先级**: 🟢 低  
**需求描述**: 分数兑换虚拟奖品，提升学生参与度  
**功能要求**:
- 积分规则：签到、作业、课堂表现获得积分
- 虚拟奖品：免作业券、加分券、称号徽章
- 排行榜：周榜/月榜/学期榜
- 成就系统：连续签到7天、满分作业等

---

#### REQ-009: 家长端/只读视图
**优先级**: 🟢 低  
**需求描述**: 家长绑定学生账号，查看孩子表现  
**功能要求**:
- 家长注册绑定学生
- 查看：签到记录、成绩、作业状态
- 接收通知
- 只读权限，不可操作

---

#### REQ-010: 课堂互动工具
**优先级**: 🟢 低  
**需求描述**: 增强课堂互动性的小工具  
**功能要求**:
- 随机抽问：从已签到学生随机选择
- 实时投票：选择题，学生手机端投票，大屏展示结果
- 弹幕提问：学生匿名提问，教师筛选展示

---

## 3. 非功能需求

### 3.1 性能需求
- 课表页面加载时间 < 2秒
- 签到操作响应时间 < 500ms
- 报表导出支持500人班级 < 5秒

### 3.2 兼容性需求
- 支持 Chrome、Edge、Firefox、Safari 最新两版
- 移动端适配（学生主要用手机）

### 3.3 安全需求
- 学生数据隔离（只能看自己的）
- 教师数据边界（只能管理负责班级）
- 操作日志记录（成绩修改、请假审批等敏感操作）
