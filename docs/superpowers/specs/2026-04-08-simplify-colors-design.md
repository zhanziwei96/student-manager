# ClassHub 颜色系统简化设计文档

**日期**: 2026-04-08  
**作者**: Claude Code  
**状态**: 已批准  

---

## 1. 问题陈述

### 1.1 当前问题
当前 ClassHub 前端颜色系统过于复杂，导致视觉杂乱：

| 组件 | 当前颜色数量 | 具体颜色 |
|------|-------------|----------|
| 统计卡片 | 4 色 | 蓝、绿、紫、橙 |
| 课程主题 | 4 色 | 蓝、绿、紫、橙 |
| 状态指示 | 3 色 | 绿、蓝、红 |
| 调课标签 | 3 色 | 蓝、紫、红 |

### 1.2 用户反馈
"当前页面感觉颜色太多太杂，让人眼花缭乱"

---

## 2. 设计目标

将多色杂乱体系简化为**双主色 + 三状态色**的精简系统：

- **提升专业感**: 统一色调，减少视觉噪音
- **强化品牌**: 突出 Indigo 主色识别度
- **明确语义**: 状态色只用于真正的状态反馈
- **保持一致**: 相同类型的元素使用相同颜色

---

## 3. 目标颜色体系

### 3.1 核心颜色

```
主色 Indigo:    #6366f1  (主要操作、卡片、信息)
强调色 Cyan:    #22d3ee  (渐变、装饰性高亮)
```

### 3.2 状态颜色（仅用于状态反馈）

```
Success:    #22c55e  (成功、进行中、高签到率)
Warning:    #f59e0b  (警告、调课、中等签到率)
Error:      #ef4444  (错误、停课、低签到率)
```

### 3.3 中性颜色

```
背景:       #030307 / #0a0a0f
卡片背景:   rgba(255,255,255,0.03)
边框:       rgba(255,255,255,0.1)
文字主色:   #ffffff
文字次色:   rgba(255,255,255,0.7)
```

## 4. 具体实施方案

### 4.1 统计卡片简化

**当前**: 4 色卡片（蓝绿紫橙）  
**目标**: 统一 Indigo 主色

```css
/* 主统计卡片 */
--card-indigo-bg: rgba(99, 102, 241, 0.15);
--card-indigo-border: rgba(99, 102, 241, 0.4);
--card-indigo-icon-bg: rgba(129, 140, 248, 0.3);
--card-indigo-icon-text: #a5b4fc;
```

### 4.2 课程表简化

**当前**: 4 色随机分配  
**目标**: Indigo 单色系，用透明度区分

| 优先级 | 透明度 | 用途 |
|--------|--------|------|
| 高 | 25% | 当前课程、重点课程 |
| 中 | 15% | 普通课程 |
| 低 | 8% | 背景、次要课程 |

### 4.3 调课标签简化

**当前**: 蓝(调课)、紫(补课)、红(停课)  
**目标**:

| 类型 | 颜色 | 理由 |
|------|------|------|
| 调课 | Indigo | 主操作色 |
| 补课 | Warning | 需要特别注意 |
| 停课 | Error | 负面状态 |

### 4.4 签到率指示简化

**当前**: 绿(≥90)、蓝(≥70)、红(<70)  
**目标**:

| 签到率 | 颜色 | 语义 |
|--------|------|------|
| ≥90% | Success | 优秀 |
| ≥60% | Neutral | 及格 |
| <60% | Error | 需关注 |

## 7. 反模式避免

- **不要**在组件级别硬编码颜色
- **不要**为不同数据类型分配不同颜色
- **不要**使用颜色作为唯一的信息传递方式（配合图标/文字）
