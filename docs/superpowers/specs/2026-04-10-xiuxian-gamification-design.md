# 七十二变学堂 — 游戏化学习系统设计文档

日期: 2026-04-10
状态: 已批准

## 概述

基于黑神话悟空 × 无尽冬日的灵感，为 ClassHub 添加游戏化学习系统。学生在一个修仙世界中修行（个人成长线）和建设仙门（团队协作线），把签到、作业、考试、PPT 展示等学习活动融入游戏机制。

## 核心玩法

### 双线并行

- **个人修炼线**（黑神话悟空）：角色成长、72变解锁、Boss 战
- **仙门建设线**（无尽冬日）：基地建设、资源管理、团队协作

## 子系统 B：个人修炼 — 72 变系统

### 积分 → 修为映射

直接复用现有积分系统（70分起步），无需双轨制。学生积分变化时自动计算对应等级：

- 积分 70 → 凡人
- 积分 75 → 练气期（解锁第1张变身卡）
- 积分 80 → 筑基期
- 积分 85 → 金丹期
- 积分 90 → 元婴期
- 积分 95 → 化神期（解锁传说级变身卡）

### 变身卡解锁

每个等级解锁 2-3 张变身卡，学生可自由选择装备。变身卡影响头像外观。

初始变身卡池（参考黑神话悟空的角色体系）：

| 稀有度 | 可解锁角色 |
|--------|-----------|
| 普通 | 小妖、山神、土地公 |
| 稀有 | 行者、剑仙、狐仙 |
| 史诗 | 天蓬元帅、卷帘大将、二郎神 |
| 传说 | 齐天大圣、哪吒、观音弟子 |

### 签到 → 采药

- 每日签到 = 一次"采药"行为
- 基础奖励：灵晶 +5
- 连续签到奖励：
  - 3天连续：灵晶 +8
  - 7天连续：灵晶 +12 + 随机变身卡碎片
  - 30天连续：灵晶 +20 + 稀有变身卡

## 子系统 C：仙门建设 — 基地系统

### 仙门创建与加入

1. 老师在后台开启"开山立派"功能
2. 学生可以：
   - 创建新仙门（自定义名称和口号）→ 成为门主
   - 加入已有仙门（人数上限 6 人）
3. 地图视图：显示所有仙门的位置，已加入的仙门高亮
4. 加入后不可随意更换（需门主同意或老师操作）

### 资源产出

学习活动自动转化为仙门资源（无需学生手动操作）：

| 活动 | 产出 | 触发条件 |
|------|------|----------|
| 签到 | 灵晶 ×5 | 每日签到时 |
| 作业提交 | 仙木 ×10 | 作业完成时 |
| 考试高分 | 天铁 ×15 | 考试分数 ≥80 时 |
| 帮助同学 | 灵晶 ×3 | 被帮助者确认后 |

### 建筑升级

- 门主或副门主可发起升级提案
- 消耗仙门资源
- 升级后全体成员获得对应加成
- 仙门总外观随建筑总等级变化：
  - 总等级 1-5：茅草小屋
  - 总等级 6-15：青砖道观
  - 总等级 16-25：琉璃仙宫

## 子系统 D：论道大会 — PPT 评分

### 流程

1. **准备期**（考前 2 周）：老师创建论道大会，设定参与仙门
2. **论道日**：
   - 各仙门按抽签/论道帖数量决定顺序上台
   - 每组展示 PPT（5-10 分钟）
3. **评分**：
   - 其他仙门成员每人可投 1-5 星（"天劫"评分）
   - 老师评分权重 ×3（"天道裁决"）
   - 实时显示各组"口碑值"（像 Boss 血条）
4. **结算**：
   - 第一名仙门获得"道祖传承"称号 + 建筑特殊装饰
   - 个人分数按排名获得加成（+5/+3/+1）

### 评分计算

```
仙门得分 = (Σ(其他组评分) / 评分人数) × 0.4 + 老师评分 × 0.6
个人得分 = 仙门得分 × 个人贡献系数
```

## 与现有系统的集成点

|----------|-------------|------|

## 实施拆分（5 个子项目）

每个子项目独立可测试、可部署：

1. **P1：数据基础 + 后端 API** — 数据模型、迁移、CRUD、核心 API
2. **P2：个人修炼系统** — 等级计算、变身卡、签到采药、个人页面
3. **P3：仙门系统** — 创建/加入/退出、资源产出、地图可视化
4. **P4：建筑与加成** — 建筑升级、积分加成计算、仙门详情页
5. **P5：论道大会** — 评分系统、投票、实时展示、结算

依赖关系：P1 → P2 → P3 → P4 → P5（顺序执行）
