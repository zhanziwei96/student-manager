## 1. 新架构数据锚点速览

| 表 | 含义 | 角色主线 |
|----|------|---------|
| `cohorts` | 届（入学年份） | 身份线 |
| `classes` | 班级（届+专业下的班） | 身份线 |
| `students` | 学生（含 status 学籍状态） | 身份线 |
| `semesters` | 学期（实体化，替代 .env） | 时间线 |
| `courses` | 课程目录（编码/名称/院系） | 课程线 |
| `course_offerings` | 教学班（课程×学期×教师×范围） | 课程线 |
| `enrollments` | 选课（学生×教学班×学期）：个人成绩 score + 期末成绩 final_score | 课程线 |
| `groups` | 小组（班级×学期×科目）：小组累计分，无任务维度 | 小组 |
| `student_class_semesters` | 学生-行政班-学期归属 | 身份×时间 |
| ~~teacher_class_semesters~~ | ❌ 已确认移除：教师授课关系唯一真源 = course_offerings.teacher_id | - |

**状态图例**：✅ 已实现 ｜ 🔄 重构适配（功能已有，数据锚点迁移） ｜ ➕ 新架构新增 ｜ 📋 规划中（原 REQ 清单）

## 6. 非功能需求增量（新架构相关）

| 需求 | 说明 |
|------|------|
| 学期切换原子性 | rollover 分步事务 + 互斥（重构方案 4.6），切换失败可回滚 |
| 缓存一致性 | 学期/班级映射缓存 TTL + 关键操作后手动失效（重构方案 4.2） |
| FK 完整性 | 所有 FK 列建索引；关键关系 RESTRICT（重构方案 4.1/4.7） |
| 权限边界 | 教师权限从 `course_offerings` 派生；学生只能看自己的数据 |
| 兼容过渡 | 双写过渡期新旧字段并存，Phase 4 统一清理 |

## 7. 各角色操作速览对比（现状 vs 新架构）

| 维度 | 管理员 | 教师 | 学生 |
|------|--------|------|------|
| 核心新增 | 届/学期/课程/教学班/选课管理、rollover | 我的教学班（派生权限）、期末成绩登记 | 我的成绩查看（各科/期末/小组） |
| 核心适配 | 课表/账号/审计 | 签到/打分/小组/排行榜 | 签到/小组/排名 |
| 边界变化 | 无班级范围限制，需学期维度 | 从"管班"变为"授课"（教学班边界） | 不变（只看自己） |
