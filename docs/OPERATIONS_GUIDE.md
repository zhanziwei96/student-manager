## 1. 登录与账号

### 1.1 登录

1. 浏览器打开系统地址（开发环境默认 `http://localhost:5174`，正式地址由部署方提供）。
2. 在登录页选择**角色**：管理员 / 教师 / 学生。
3. 输入**用户名**与**密码**，点「登录」。

登录成功后由系统根据**账号自身的角色**跳转，分别进入 `/admin`、`/teacher` 或 `/student` 首页。

> ⚠️ 角色必须与账号匹配。若提示「用户名或密码错误」，除了检查用户名和密码，也要确认**所选角色**是否正确（同一个用户名只在它所属角色的入口登录）。

### 1.2 登录失败的可能提示

| 提示 | 含义 | 处理 |
|---|---|---|
| 用户名或密码错误 | 用户名、密码或所选角色不匹配 | 核对三者；忘记密码请联系管理员重置 |
| 账号已被禁用 | 该账号被停用 | 联系管理员启用 |
| 请求过于频繁（约 1 分钟后重试） | 触发了登录限流 | 等待约 1 分钟再试 |

### 1.3 修改密码

1. 点右上角**头像/菜单** → 「修改密码」。
2. 填写：**旧密码**、**新密码**（至少 6 个字符）、**确认新密码**。
3. 点保存。

校验提示（原文）：`请输入旧密码` / `请输入新密码` / `新密码至少需要 6 个字符` / `两次输入的新密码不一致`。

### 1.4 退出登录

点右上角菜单中的「退出登录」即可。退出后回到登录页，再进入需重新登录。

### 3.2 学期管理

**入口**：核心管理 → 学期管理
**页面说明**：管理学期，切换当前学期并复制开学数据

![学期管理](images/operations/admin-semesters.jpg)

表格列：`学期`、`开学日期`、`周数`、`状态`、`操作`。当前学期在「学期」列带**当前**徽标；状态为 `进行中` / `已归档`。

| 我要做什么 | 怎么做 |
|---|---|
| 新建学期 | 点「创建学期」→ 填 **学期标识**（建议 `学年-学期` 格式，如 `2026-2027-1`）、**开学日期**、**总周数**（默认 20，允许 1–30）→ 创建 |
| 改开学日期 / 周数 | 点该行铅笔图标 → 修改 → 保存 |
| 切换当前学期 | 点该行「设为当前」→ 确认。弹窗原文：**确定切换到 '{学期标识}' 吗？签到、课表与成绩数据都将按该学期口径展示。** |
| 复制上一学期 | 点「复制上一学期」→ 开始复制。原文：**将上一学期的学生行政班归属、开课计划与选课名单复制到当前学期（教师默认留任）。请先创建并切换目标学期。** |

> ⚠️ 三个要点
> 1. **学期标识创建后不可修改**，只可改日期与周数。
> 2. 「设为当前」只对状态为 `进行中` 的学期显示；`已归档` 学期不能设为当前。
> 3. 全站同一时间只有一个当前学期。切换后，签到、课表、成绩与统计都按新学期的口径展示。

### 3.4 班级管理

**入口**：核心管理 → 班级管理
**页面说明**：按届管理班级，创建后可为学生分配

![班级管理](images/operations/admin-classes.jpg)

**表格上方筛选**：届（`全部届` / 具体届）、显示范围（`在用班级` 默认 / `含已归档`）
表格列：`班级`、`专业`、`所属届`、`状态`、`学生数`、`操作`；状态为 `在用` / `已归档`。

#### 创建班级（支持一次建多个）

点「创建班级」，填三项：

| 字段 | 说明 |
|---|---|
| 所属届 | 下拉选择，如 `2026届` |
| 专业 | 如 `计算机科学与技术` |
| 班级名 | 支持批量写法：`1-5`（范围）或 `1班,3班`（枚举），分隔符可用 `,` `，` `、` |

- 输入时下方实时预览：**将创建：1班、2班、3班…**（超过 5 个显示前 5 个 + 等 N 个）
- 创建结果提示：`已创建 3 个班级`；若有重名：`已创建 2 个班级，跳过 1 个已存在`

输入 `3-5` 时的弹窗效果（下方蓝字即为预览）：

![创建班级](images/operations/admin-classes-create.jpg)

**班级显示名规则**：`{届}届{专业}{班级名}`，例如 `2026届计算机科学与技术1班`。系统内所有下拉框都显示这个完整名 —— 因为不同专业可能有同名班级。

#### 改名 / 归档 / 恢复 / 删除

| 操作 | 说明 |
|---|---|
| 编辑（铅笔图标） | 可改**班级名**与**专业**，所属届不可改 |
| 归档 | 原文：确定要归档 '{班级显示名}' 吗？归档后不再出现在班级列表与下拉中，历史课堂、签到与成绩完整保留，可随时恢复。 |
| 恢复 | 点击即恢复，无二次确认 |
| 删除（红色垃圾桶） | 原文：确定要删除 '{班级显示名}' 吗？班级仍被学生、课表、课堂等引用时将无法删除。 |

> 💡 **归档还是删除？**
> - 班级毕业、本学期不再开课 → 用**归档**（数据保留，可恢复）
> - 班级是建错的、且没有学生和课表 → 用**删除**
> - 删除失败通常说明该班仍被学生、课表或课堂引用，请改用归档

### 3.6 教学班管理（开课 + 选课名单）

**入口**：核心管理 → 教学班
**页面说明**：按学期开课、安排教师并管理选课名单

![教学班管理](images/operations/admin-offerings.jpg)

顶部按**学期**筛选（默认当前学期）。表格列：`课程`、`学期`、`教师`、`面向范围`、`容量`、`状态`、`操作`。
- 教师为空显示 `待安排`；容量为空显示 `不限`；状态为 `开课中` / `已结课`。

#### 创建一个教学班

点「创建教学班」，填：

| 字段 | 说明 |
|---|---|
| 课程 | 下拉，显示为 `课程名（编码）` |
| 学期 | 默认预填当前学期 |
| 教师 | 可先选 `待安排`，之后再指派 |
| 面向范围 | 勾选班级，决定**这位教师能管理哪些班的学生**（详见下方说明） |
| 容量 | 选课人数上限，可留空表示不限 |

**面向范围怎么用**（重要）：

- 提供「全选 / 清空」按钮，班级按 `{届}届 · {专业}` 分组
- **一个班都不选 = 面向全部班级（通配）** —— 教师可以看到全校学生
- 选了若干班 = 教师只能看到这些班的学生（这是教师权限的依据）
- 仅「在用」班级可选，已归档班级不出现

> 💡 只想给某个老师带一个班的课，就只勾选那个班；想让老师带全年级，勾选对应几个班；无特殊要求才留空（通配）。

创建教学班弹窗（面向范围按「届 · 专业」分组）：

![创建教学班](images/operations/admin-offering-create.jpg)

#### 编辑教学班

点铅笔图标 → 可改 **教师**、**面向范围**、**容量**。保存时面向范围是**整体替换**：清空所有勾选即改回「面向全部班级」。

#### 管理选课名单

在列表中点某教学班的「**名单**」按钮。弹窗标题为 `{课程名} · 选课名单`，说明：批量导入学号（每行一个），退课保留历史记录。

![选课名单弹窗](images/operations/admin-roster-dialog.jpg)

（上图是搜索 `2513010202` 后的效果：`名单 · 共 106 人（筛选出 1 人）`。）

两种加人方式：

| 方式 | 步骤 | 结果提示 |
|---|---|---|
| 按班级加入名单 | 选班级 → 点「加入名单」 | `按班级加入 106 人，跳过 0 人`。提示原文：**加入所选班级的全部在读学生（已在名单中的会保留）** |
| 批量导入学号 | 在文本框每行输入一个学号 → 点「导入」 | `导入 28 人，跳过 3 人`（跳过的是已在名单中的） |

名单区：

- 标题显示 **名单 · 共 106 人**；搜索后追加 **（筛选出 1 人）**
- 搜索框：**搜索学号或姓名...**，输入即过滤
- 表格列：`学号`、`姓名`、`班级`、`平时成绩`、`期末成绩`、`操作`（期末成绩未登记显示 `—`）
- 行内「退课」：**点击即退课，无二次确认**；退课保留历史记录（成绩与记录不丢）
- 搜索无结果时提示：`没有匹配的学生` / `换个学号或姓名试试`

> 💡 每打开一次弹窗，搜索框会自动清空，避免上次的搜索词挡住新数据。

### 3.7 学生管理

**入口**：人员管理 → 学生管理
**页面说明**：管理学生档案和分数

![学生管理](images/operations/admin-students.jpg)

顶部三个按钮：`批量导入`、`批量禁用毕业生账号`、`添加学生`。筛选区：**届筛选**、**班级筛选**、**搜索学生**（占位 `输入姓名或学号搜索...`）。

表格列：`学号`、`姓名`、`班级`、`学籍`、`账号`、`操作`（每页 50 人，分页显示 `1 / 3（共 106 人）`；搜索时显示 `找到 N 名匹配的学生`）。

| 我要做什么 | 怎么做 |
|---|---|
| 加一个学生 | 点「添加学生」→ 填 `学号`、`姓名`、`所属届`、`班级` → 添加。提示：`学生 张三 添加成功` |
| 改学籍状态 | 点该生「学籍」→ 选 `在读` / `休学` / `退学` / `毕业` → 保存。原文：**休学/退学/毕业的学生将保留历史数据** |
| 转班 | 点该生「转班」→ 选 `目标届` 与 `目标班级` → 确认转班 |
| 批量加人 | 点「批量导入」（见下） |
| 毕业清账号 | 点「批量禁用毕业生账号」→ 勾选班级 → 确认禁用。原文：**禁用后学生无法登录（适用于毕业/离校学生）** |

#### 批量导入学生（Excel）

![批量导入学生](images/operations/admin-student-import.jpg)

1. 点「下载导入模板」得到 `学生导入模板.xlsx`（含「学生名单」与「填写说明」两个工作表）。
2. 按模板填写 —— 列头为：`学号`、`姓名`、`所属届`、`专业`、`班级名`。

   | 列 | 说明（模板原文） |
   |---|---|
   | 学号 | 必填，唯一。已存在的学号会被跳过（不会修改既有学生） |
   | 姓名 | 必填 |
   | 所属届 | 如 `2025`；班级不存在时用于自动建班，班级已存在可留空 |
   | 专业 | 必填，如 `康复治疗技术`（与「所属届 + 班级名」一起定位班级） |
   | 班级名 | 必填，如 `1班`（**只写班名**，不要带届和专业；完整班级名由系统按「届+专业+班名」拼成） |

3. 点「选择文件」（仅 `.xlsx`）→ 点「导入」。
4. 结果：`成功 106 跳过 3`，逐行列出失败/跳过原因。

> ⚠️ 注意事项
> - **初始密码默认为学号**，请提醒学生首次登录后改密码。
> - **学号已存在会被跳过**，不会更新已有学生的信息；要改信息请在列表里编辑。
> - **班级不存在时会自动建班**（按届+专业+班名）；若班级不存在且**没填所属届**，该行会失败并提示 `班级「…」不存在且未填写所属届`。
> - 限制：单次最多 **2000 行**、文件最大 **10MB**、只接受 `.xlsx`；缺列会提示 `缺少必需列: …（请使用导入模板）`。
> - 班级名留空或写 `未分班` 的学生**不挂到任何班**。

> 💡 **为什么列表里只看到部分学生？**

### 4.3 成绩录入（加减分 / 期末成绩）

**入口**：我的教学班 → 成绩录入

![成绩录入](images/operations/teacher-grades.jpg)

**页面结构**

- 顶部：课程名 + `{面向范围} · 共 106 名学生`，筛选后追加 `（筛选出 1 人）`
- 工具栏：**搜索学号或姓名...** + **班级下拉**（`全部班级（106 人）`、`2025届康复治疗技术1班（54 人）`…）
- 名单**按行政班分组**，组标题形如 `2025届康复治疗技术1班 54 人`
- 表格列：`学号`、`姓名`、`平时成绩`、`期末成绩`、`操作`（未登记期末分显示 `—`）

> 💡 106 人的名单不要靠翻找：直接搜学号或姓名，或把班级切到目标班。

#### 加减分（平时成绩）

![加减分弹窗](images/operations/teacher-score-dialog.jpg)

点某学生的「加减分」：

1. **分数变化（正数加分，负数减分）**：填 `5` 或 `-3`
2. **原因**：必填；可直接点下方**快捷标签**，标签会同时填入原因与分值
3. 点「保存」→ 提示 `分数已更新`

**快捷标签**（可直接点）：

| 加分（+2） | 减分 |
|---|---|
| 课堂积极发言、课堂表现优秀、作业完成优秀、小组协作积极、帮助同学/答疑、进步明显、全勤、竞赛/活动获奖 | 课堂违纪 `-2`、作业未交 `-2`、旷课 `-5` |

> ⚠️ 注意事项
> - **原因必填**（最多 200 字），不填会提示 `请输入分数变化原因`。
> - 分数是**累加**的：新分 = 当前分 + 变化值，然后**限制在 0–100 之间**。例如 0 分的旷课 `-5` 仍是 0 分。
> - 若同时在别处改过这个学生，保存时会提示 `分数已被其他用户修改，请刷新后重试`，刷新页面再操作。
> - 每次加减分都会记录**操作人与原因**，可在小组页的「分数日志」等处查到。

#### 期末成绩：两种方式

| 方式 | 适用 | 操作 |
|---|---|---|
| **期末分**（单人） | 试卷考试，每人分数不同 | 点学生「期末分」→ 填分数（如 88）→ 登记。原文提示：**试卷考试使用个人分数；任务考核请用「期末任务同分」** |
| **期末任务同分**（整组） | 小组任务考核，组内同分 | 点右上「期末任务同分」→ 选 `班级` + `小组` + `期末成绩` → 登记，提示 `期末成绩已登记（6 人）` |

![期末任务同分](images/operations/teacher-group-final.jpg)

> ⚠️ 「期末任务同分」只影响**该小组成员中、选了这门课**的学生；小组在「小组管理」里创建。
> ⚠️ 期末分是**直接赋值**（不是累加），输入框不限制 0–100，请自行填合理分数。

## 5. 开学准备清单

按下面的顺序做，一次跑通整条链路（前 7 步是**一次性基础数据**，第 8 步起**每学期重复**）。

### 5.1 基础数据（管理员，通常只做一次）

| # | 做什么 | 去哪做 |
|---|---|---|
| 1 | 建**届**（如 `2026届`） | 核心管理 → 届管理 → 创建届 |
| 2 | 建**班级**（所属届 + 专业 + 班级名，支持 `1-5` 一次建多个） | 核心管理 → 班级管理 → 创建班级 |
| 3 | 建**课程**（如 `MATH1001 高等数学`） | 核心管理 → 课程管理 → 创建课程 |
| 4 | 建**学期**并「设为当前」 | 核心管理 → 学期管理 |
| 5 | 建**教师账号**，把用户名与初始密码交给老师 | 人员管理 → 教师管理 → 添加教师 |
| 6 | **导入学生**（Excel 模板，初始密码=学号） | 人员管理 → 学生管理 → 批量导入 |
| 7 | （可选）**导入课表**，教师端「今日课表」才有内容 | 教学运营 → 课表管理 → 导入课表 |

### 5.2 每学期开课（管理员）

| # | 做什么 | 去哪做 |
|---|---|---|
| 8 | **开教学班**：选课程 + 学期 + 教师 + **面向范围** + 容量 | 核心管理 → 教学班 → 创建教学班 |
| 9 | **导入选课名单**：推荐「按班级加入名单」一键收全班 | 教学班 → 该行的「名单」 |

### 5.3 学期结束 / 新学期开始（管理员）

| # | 做什么 | 去哪做 |
|---|---|---|
| 10 | 建新学期 →「设为当前」→ 点「复制上一学期」（带过开班计划、选课名单与学生班级归属，教师默认留任） | 核心管理 → 学期管理 |
| 11 | 毕业处理：班级**归档** → 届**毕业归档** → 学生**批量禁用毕业生账号** | 班级管理 / 届管理 / 学生管理 |

### 5.4 教师每个班的日常

| 场景 | 操作 |
|---|---|
| 上课前 | 课堂签到 → 开始课堂（学生用验证码或学号签到） |
| 课堂表现 | 我的教学班 → 成绩录入 → 加减分（个人），或小组管理 → 加减分（小组） |
| 期末 | 试卷 → 逐个「期末分」；小组任务 → 「期末任务同分」 |
| 看排名 | 排行榜（按科目切换个人/小组、班内/跨班） |

## 6. 常见问题

### 6.1 登录与账号

| 问题 | 原因与处理 |
|---|---|
| 提示「用户名或密码错误」 | 三点都要对：**用户名、密码、所选角色**。同一个用户名只在它所属角色的入口能登录（教师账号选「教师」） |
| 教师忘了密码 | 管理员在 **教师管理 → 重置密码** 里设新密码 |
| 学生忘了密码 | 管理员在 **学生管理** 里改；批量导入的学生**初始密码就是学号** |
| 提示「账号已被禁用」 | 联系管理员启用账号（毕业生账号可能被批量禁用） |
| 提示登录过于频繁 | 触发了登录限流，等约 1 分钟再试 |

### 6.2 数据与权限

| 问题 | 原因与处理 |
|---|---|
| 学生管理里只有一部分学生 | 页面**默认选中第一个班级**。切换班级/届，或用搜索框按姓名、学号搜索 |
| 教师看不到某个班的学生 | 该教师的教学班「**面向范围**」里没有勾这个班；到 教学班 → 编辑 里补勾（不勾任何班＝面向全部班级） |
| 教学班名单是空的 | 名单要单独导入：教学班 →「名单」→「按班级加入名单」或批量导入学号 |
| 班级删不掉 | 该班仍被学生、课表或课堂引用。改用「**归档**」：数据保留、列表中隐藏、可恢复 |
| 分数加了没变化 | 分数被限制在 **0–100**：0 分学生的减分不会变成负数，100 分学生的加分不会超过 100 |
| 保存分数时提示「分数已被其他用户修改」 | 同一学生被别处改过，刷新页面再操作 |
| 期末成绩用哪种方式 | 试卷考试用「**期末分**」（每人不同）；小组任务用「**期末任务同分**」（组内同分） |
| 课表导入报「班级不存在或所有学生已禁用」 | 课表导入**不自动建班**，先在班级管理里建好班级 |
| 导入课表报「课程已存在（…）」 | 同一班级、同一天、同一时间已有同一门课，避免重复导入 |
| 教师账号能登录但没有教学班 | 管理员还没给他开教学班，或教学班不在**当前学期** |

### 6.3 已知问题

|---|---|---|
| 登录失败提示 | 角色选错时也提示「用户名或密码错误」，不够明确 | 记住：用户名、密码、角色三者必须匹配 |
